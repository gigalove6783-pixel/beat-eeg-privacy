BEAT Audit Live

BCI(뇌-컴퓨터 인터페이스)가 내보내는 출력으로, 두 기록이 같은 사람의 것인지 연결할 수 있는지 지금 이 자리에서 잽니다.

공격자는 BCI 출력과, 있으면 각 시행의 과제 단서를 봅니다. 대상 사용자를 등록한 적은 없습니다.

AUC(구별 점수): 0.5 = 우연, 1 = 항상 구별. 두 기록을 같은 사람으로 연결하는 점수이며 신원 확인율이 아닙니다.

이 페이지는 로컬 감사 서버와 함께 동작합니다

파일을 끌어 놓으면 이 컴퓨터의 서버가 beat_audit로 실제 감사를 계산합니다. 지금은 서버에 연결되어 있지 않습니다.

  1. 프로젝트 폴더(BEAT PROJECT)에서 터미널을 엽니다.
  2. .venv\Scripts\python demo/live/server.py 를 실행합니다.
  3. 표시된 주소 http://127.0.0.1:8737/ 를 브라우저로 엽니다.

네트워크는 쓰지 않습니다. 서버는 이 컴퓨터(127.0.0.1)에서만 열립니다.
